# Large artifacts not included

Full checkpoints, prediction-mask caches, raw LIVECell images/annotations, large tensors, full server logs and per-ground-truth intermediate outputs are omitted. Available checkpoint/annotation hashes and model/image inventories remain.

Obtain LIVECell from the original release under its applicable terms. The study used a locally prepared annotation with stored mask grids, so the original release alone may not reproduce that file byte for byte.

The qualitative Figure 2 image is omitted from the public candidate because it contains LIVECell-derived imagery; it remains in the author-controlled manuscript source.

No promise is made that checkpoints, caches or dataset derivatives will be publicly distributed. Size, rights and artifact availability need a separate release decision. This archive alone cannot reproduce everything.
